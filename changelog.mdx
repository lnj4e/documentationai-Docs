## Recent Updates

- Introduced bulk claim upload supporting CSV and PDF formats

- Enhanced search functionality with fuzzy matching for claim notes
- Optimized API response times by 40% for high-volume queries

- Fixed intermittent failures in webhook delivery for claim status updates

## How to Stay Updated

<Callout kind="tip">

Subscribe to our changelog feed or set up webhooks to receive notifications about new releases directly in your workflow.

</Callout>

Follow these steps to integrate changelog updates into your tools:

<Steps>

<Step title="Set Up Webhook" icon="zap">

Configure a webhook endpoint to receive update payloads from `https://api.example.com/v1/webhooks/changelog`.

````json
{
  "version": "1.2.0",
  "tags": ["feature"],
  "changes": ["New denial prediction"]
}
````

</Step>

<Step title="RSS Feed" icon="rss">

Add this RSS feed to your reader: `https://docs.example.com/changelog.xml`.

</Step>

<Step title="API Polling" icon="refresh-cw">

Query the latest version:

<CodeGroup tabs="JavaScript,cURL">

````javascript
const response = await fetch('https://api.example.com/v1/releases/latest');
const latest = await response.json();
console.log(latest.version);
````

````bash
curl https://api.example.com/v1/releases/latest \
  -H "Authorization: Bearer YOUR_TOKEN"
````

</CodeGroup>

</Step>

</Steps>

const upload = {
