## Prerequisites

<Callout kind="info" title="Before You Begin">
Ensure you have:
- A valid email address
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- Stable internet connection
</Callout>

Claim Clarity helps you organize and manage project documentation efficiently. Follow these steps to get started quickly.

## Create and Verify Your Account

Sign up at [https://claimclarity.ai](https://claimclarity.ai) to access your documentation space.

<Steps>
  <Step title="Sign Up" icon="user-plus">
    Navigate to the sign-in page and click "Sign Up" or use the registration form.
    
    Enter your email and create a strong password.
  </Step>
  <Step title="Verify Email" icon="mail">
    Check your inbox for a verification email from Claim Clarity.
    
    Click the verification link to activate your account.
  </Step>
  <Step title="Log In" icon="log-in">
    Return to [https://claimclarity.ai](https://claimclarity.ai) and sign in with your credentials.
  </Step>
</Steps>

<Callout kind="tip">
If you encounter issues, use the "Forgot your password?" link to reset access.
</Callout>

## Navigate the Dashboard

After logging in, you land on the main dashboard. Key areas include:

- **Project Spaces**: List of your documentation projects
- **Recent Documents**: Quick access to edited files
- **Search Bar**: Find content across spaces
- **Settings**: Manage account and integrations

Use the left sidebar for navigation and the top bar for global actions like creating new spaces.

## Set Up Your First Project Space

Project spaces organize related documentation.

<Steps>
  <Step title="Create Space" icon="folder-plus">
    Click "New Space" in the dashboard.
    
    Name it (e.g., "My Project Docs") and add a description.
  </Step>
  <Step title="Configure Space" icon="settings">
    Set permissions: public, private, or team access.
    
    Optionally, add a custom logo or color theme.
  </Step>
</Steps>

## Create and Import Documents

Start building your documentation.

<Tabs>
  <Tab title="Create New Document" icon="file-plus">
    In your space, click "New Document".
    
    Choose Markdown or rich text editor.
    
    <CodeGroup tabs="Markdown,Rich Text">
    ````markdown
    # Welcome to My Project
      
    This is your first document.
      
    ## Features
    - Easy editing
    - Real-time collaboration
    ````
    ````
    <p>Rich text supports headings, lists, and embeds. Use the toolbar for formatting.</p>
    ````
    </CodeGroup>
  </Tab>
  <Tab title="Import Existing" icon="upload">
    Select "Import" and upload Markdown files or connect GitHub repo.
    
    Supported formats: `.md`, `.markdown`, Git repos.
  </Tab>
</Tabs>
